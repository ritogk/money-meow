プライバシーポリシー

1. はじめに

money-meow（以下「本アプリ」）は、個人が自身のGmailアカウントからクレジットカードの請求メールを取得し、家計管理を行うための個人利用アプリケーションです。本プライバシーポリシーは、本アプリにおける情報の取り扱いについて説明します。

2. 取得する情報

本アプリは、Google OAuth 2.0 を使用して以下の情報にアクセスします:

  • Gmailメールデータ（読み取り専用）: クレジットカード会社からの請求確定メールの件名および本文を検索・取得します。

本アプリがアクセスするGmailのスコープは gmail.readonly（読み取り専用）のみであり、メールの送信・削除・変更は一切行いません。

3. 情報の利用目的

取得した情報は以下の目的にのみ使用します:

  • クレジットカードの請求金額の抽出
  • 月間の利用可能金額の計算
  • 計算結果のLINEへの通知

4. 情報の保存

本アプリは取得したメールデータを永続的に保存しません。メールの内容はLambda関数の実行中にのみメモリ上で処理され、実行完了後に破棄されます。

認証に必要なOAuthトークンは、AWS Systems Manager Parameter Store に暗号化して保存されます。

5. 第三者への提供

本アプリが取得した情報を第三者に提供・販売・共有することはありません。ただし、計算結果のみがLINE Messaging APIを通じてユーザー自身のLINEアカウントに送信されます。

6. セキュリティ

本アプリは以下のセキュリティ対策を実施しています:

  • 認証情報はAWS Systems Manager Parameter Store（SecureString）で暗号化保管
  • Gmail APIへのアクセスは最小権限（読み取り専用）に制限
  • AWS Lambda上で実行され、実行環境は一時的なもの

7. ユーザーの権利

ユーザーはいつでも以下の操作を行うことができます:

  • Googleアカウント設定から本アプリのアクセス権を取り消す
  • 本アプリの使用を中止する

8. Google API Services User Data Policy

本アプリのGoogle APIサービスから受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に準拠します。

9. 変更について

本プライバシーポリシーは必要に応じて更新されることがあります。重要な変更がある場合は、本ページにて通知します。

利用規約

1. 本アプリについて

money-meowは、個人の家計管理を目的とした非商用のアプリケーションです。Gmailからクレジットカードの請求メールを読み取り、月間の利用可能金額を計算してLINEで通知します。

2. 利用条件

  • 本アプリは個人利用を目的としています。
  • 利用にはGoogleアカウントおよびLINEアカウントが必要です。
  • 本アプリの利用にはGmail APIへの読み取りアクセスの許可が必要です。

  • メールフォーマットの変更等により、金額の取得が正常に行えない場合があります。

4. サービスの変更・終了

開発者は、事前の通知なく本アプリの機能変更、サービス停止を行う場合があります。
